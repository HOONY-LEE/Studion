# 04. UI 명세

원칙: **화면당 핵심 동작 1~2개, 내비게이션 3뎁스 이내, 탭 4개 고정.**
색상·타이포·접근성 규칙은 → [05](05-localization-a11y.md).

---

## 정보구조 (IA)

```
RootView (TabView — iPad에서 NavigationSplitView로 교체)
├─ 오늘 (Today)      house
├─ 플래너 (Planner)  calendar
├─ 성적 (Grades)     chart.bar
└─ 설정 (Settings)   gearshape
```

**탭을 5개 이상으로 늘리지 않는다.** 과목별 관리는 별도 탭이 아니라 성적 탭 안의 상세 화면이다.

내비게이션 최대 깊이:
```
성적 탭 → 과목 리스트 → 과목 상세 → 오답노트 상세/복습
  (0)        (1)          (2)            (3)
```

---

## 공통 컴포넌트 — `Views/Components/`

탭 간 공유. **iPad 2단 레이아웃에서 그대로 재사용될 수 있도록 컨테이너 너비에 반응**하게 만든다.

| 컴포넌트 | 용도 |
|---|---|
| `EmptyStateView` | 아이콘(SF Symbol) + 제목 + 설명 + 기본 동작 버튼 1개 |
| `SubjectRow` | 과목명 + 등급/성취도 배지 + 이수단위 |
| `GradeBadge` | 등급 또는 성취도 표시. 확정/추정 구분 |
| `EstimateLabel` | "추정" 배지. 추정치 옆에 **항상** 붙는다 |
| `ProgressGauge` | 목표 대비 진척. 달성=그린, 미달=뉴트럴 |
| `WrongAnswerCard` | 오답노트 카드 (텍스트 발췌 + 원인 태그 + 복습 상태) |

### 빈 상태(Empty State)는 전 화면 필수

데이터가 없는 모든 화면에 `EmptyStateView`를 둔다. 빈 리스트를 그냥 보여주지 않는다.

| 화면 | 아이콘 | 문구 | 동작 |
|---|---|---|---|
| 오늘 – 할 일 | `checklist` | 오늘 할 일이 없어요 | 할 일 추가 |
| 오늘 – 시간표 | `calendar.badge.plus` | 시간표를 등록하면 오늘 일정이 보여요 | 시간표 등록 |
| 플래너 – 시간표 | `calendar` | 등록된 시간표가 없어요 | 시간표 추가 |
| 성적 – 내신 | `book.closed` | 이수 과목을 추가해 보세요 | 과목 추가 |
| 성적 – 모의고사 | `chart.line.uptrend.xyaxis` | 첫 모의고사 회차를 추가해 보세요 | 회차 추가 |
| 과목 상세 – 오답노트 | `doc.text.image` | 틀린 문제를 찍어 오답노트를 만들어 보세요 | 사진으로 추가 |
| 복습 – due 없음 | `checkmark.circle` | 오늘 복습할 카드가 없어요 | (동작 없음) |

## 1. 오늘 (Today) 탭

**목적**: 앱을 열자마자 "오늘 뭘 해야 하나"에 답한다. 여기서 오래 머물지 않는다.

### 레이아웃 (위 → 아래)

```
┌ 네비게이션 타이틀: 오늘 (날짜 부제)      [+] 툴바 버튼 ┐
│ ① 오늘의 시간표 요약                                    │
│    학교/학원 일정 카드. 색상+레이블로 구분              │
│    ※ 길어지면 고정 높이로 자르지 말고 표시 개수를 제한  │
│      한다 (최대 3개 + "외 N개"). Dynamic Type 대응      │
│ ② 오늘의 할 일                                          │
│    체크 가능한 리스트. 탭하면 완료 토글                 │
│ ③ 이번 학기 진척 요약                                   │
│    과목별 목표 vs 최근 등급. 아주 단순한 카드            │
└─────────────────────────────────────────────────────────┘
```

### 규칙

- **추가 버튼은 1개만.** 툴바 우상단 `+`. 탭하면 "할 일 추가" 시트. 플로팅 버튼과 툴바 버튼을 동시에 두지 않는다.
- ③은 **요약**이다. 과목이 많아도 상위 몇 개만 보여주고, 자세히는 성적 탭으로 넘긴다.
- 할 일 체크는 **즉시 저장**한다. 별도 저장 버튼 없음.
- 세 섹션이 모두 비어 있으면 통합 빈 상태(온보딩 유도)를 보여준다.

## 2. 플래너 (Planner) 탭

**목적**: 시간표와 계획을 한 화면에서 본다.

### 상단 세그먼트 컨트롤: 일간 / 주간 / 월간

| 뷰 | 내용 |
|---|---|
| **일간** | 시간대별 타임라인(시간표 블록) + 해당일 할 일 리스트. 좌우 스와이프로 전날/다음날 |
| **주간** | 요일별 컬럼. 각 셀에 할 일 개수와 완료율 표시 |
| **월간** | 캘린더 그리드. 날짜별 완료율을 **색 농도**로 표시 (히트맵이되 절제된 단색 농도) |

### 시간표 표시

- 학교(`school`)와 학원(`academy`)을 **색상으로 구분**한다. 색상만으로 구분하지 말고 레이블/아이콘도 함께 둔다 (접근성 → [05](05-localization-a11y.md)).
- 겹치는 일정은 나란히 배치한다. 겹침을 숨기지 않는다.

### 시간표 등록 화면

입력 필드: 요일 · 시작/종료 시간 · 과목명/학원명 · 유형(학교/학원) · 반복 여부(**기본값 매주 반복**)

검증: `startTime < endTime`. 자정 넘김은 1차 범위에서 지원하지 않으며, 입력 시점에 막고 안내한다.

### 월간 히트맵 색 농도

완료율 0~100%를 accent color의 투명도 5단계로 표현한다. **빨강 계열을 쓰지 않는다.** 데이터 없는 날은 색 없음(테두리만).

## 3. 성적 (Grades) 탭

**최상단 세그먼트: 내신 / 모의고사**

### 3-1. 내신 서브탭

```
학년/학기 선택 (Picker 또는 상단 스크롤 칩)
  ↓
과목 리스트 (사용자가 직접 추가/삭제)
  ↓ 탭
과목 상세
```

**과목 추가 화면 — 가장 중요한 분기**

먼저 묻는다: **"이 과목은 석차등급이 산출되나요?"**

| 선택 | `evaluationType` | 이후 입력 필드 |
|---|---|---|
| 예 (일반 과목) | `achievementAndRank` | 이수단위, 원점수, 과목평균, 표준편차, 수강인원, 성취도(A~E), 석차등급, 목표등급 |
| 아니오 (성취도만) | `achievementOnly` | 이수단위, 원점수, 과목평균, 성취도(A~E) |

**"아니오"를 고르면 등급 관련 필드를 화면에서 아예 숨긴다.** 비활성화가 아니라 제거한다.
해당 과목: 사회·과학 융합선택 9개 과목, 체육·예술·교양 교과, 과학탐구실험.

> 앱은 어떤 과목이 어디 속하는지 **알지 못하고 알려고 하지 않는다.** 교육과정이 계속 바뀌므로 매핑표를 내장하지 않는다 (→ [00](00-product-principles.md) 원칙 7).

**등급 표시 규칙**

- 사용자가 입력한 `rankGrade`가 있으면 **그것을 확정값으로 크게** 표시한다.
- 원점수·평균·표준편차가 모두 있으면 추정 등급을 **보조로** 보여주되 반드시 `EstimateLabel`("추정")을 붙인다.
- 둘이 다를 수 있다. 그것을 오류로 취급하지 않는다 (정규분포 가정의 한계). 필요하면 짧은 설명 툴팁을 둔다.

**학기 요약**: 이수단위 가중 평균 등급을 학기 헤더에 표시한다. `achievementOnly` 과목은 계산에서 제외되며, 그 사실을 각주로 밝힌다.

**목표 설정 화면**: 학기별로 과목마다 목표 등급을 입력. 목표 vs 실제 비교 그래프(Swift Charts, 과목별 막대).

### 3-2. 모의고사 서브탭

```
회차 리스트 (예: "2026년 6월 학평")  — 회차명은 사용자 입력
  ↓ 탭
회차 상세: 과목별 원점수/표준점수/백분위/등급 (전부 사용자 입력)
```

- **모의고사는 항상 9등급제**다. 내신 등급제 설정과 무관하다.
- 네 값 중 일부만 입력해도 저장된다 (전부 옵셔널).
- 회차별 추이 그래프: **등급 / 백분위 / 표준점수 중 선택**해서 볼 수 있게 한다.
- 등급 추이 그래프는 **y축을 뒤집어** 1등급이 위로 오게 한다. 그러지 않으면 향상이 하락처럼 보인다.

> 앱은 등급컷을 계산하거나 추정하지 않는다. 원점수만으로 등급을 채워주지 않는다.

### 3-3. 과목 상세 화면 (내신·모의고사 공통 진입점)

> **이 화면은 두 단계가 나눠 만든다.** ①② 는 4단계, ③ 은 6단계.
> → [단계 간 공유 파일](tasks/README.md#여러-단계가-나눠-갖는-파일)

```
① 성적 추이 (해당 과목)
② 목표 대비 진척 게이지
③ 오답노트 리스트 (카드형)
   └ 영어 과목이면 하위 카테고리 필터 (독해/문법/어휘/듣기)
   └ 툴바: 오답노트 추가
```

영어 하위 카테고리 필터는 **영어 과목에서만** 노출한다. 판정 기준은 과목명이 아니라 오답노트에 `englishSubcategory`가 하나라도 설정되어 있는지 여부 — 과목명 문자열 매칭으로 판단하지 않는다.

## 4. 설정 (Settings) 탭

`Form` 기반 리스트. 섹션 순서:

| 섹션 | 항목 |
|---|---|
| 동기화 | **Apple로 로그인 (선택)** — 켜면 CloudKit 동기화 시작. 끄면 로컬 전용 |
| 모양 | 라이트 / 다크 / 시스템 (Picker 3택) |
| 언어 | 한국어 / English / 시스템 (앱 자체 전환) |
| 학사 정보 | 학년, 입학연도 → 등급제 자동 제안 + 수동 덮어쓰기 |
| 이수 과목 | 과목 리스트 추가/삭제/이름 변경 |
| 알림 | 오늘 계획 리마인드 시간, 오답 복습 알림 on/off |
| 데이터 | JSON 내보내기 / 가져오기 (Files 앱 연동) |

### 로그인 UI 규칙 (엄격)

- 로그인 항목은 **설정 탭 안에만** 존재한다. 첫 진입·온보딩·모달로 띄우지 않는다.
- 문구는 "로그인하세요"가 아니라 **"기기를 바꿔도 데이터를 유지하려면 켜세요"** 처럼 목적을 말한다.
- 로그인하지 않은 상태에서 어떤 기능도 잠기지 않는다. 잠금 아이콘·업셀 배너를 두지 않는다.

### 테마 적용 규칙

```swift
// "시스템 설정 따르기"일 때는 modifier를 아예 적용하지 않는다
.preferredColorScheme(appearance == .system ? nil : appearance.colorScheme)
```

`@AppStorage`로 선택값을 저장하고 `RootView`에서 적용한다.

## 5. 오답노트 생성 플로우 (6단계)

```
① 사진 선택 (카메라 / 사진첩)
      ↓
② Vision OCR — 온디바이스, 진행 표시
      ↓
③ 추출 텍스트 확인·수정          ← 사용자가 반드시 거치는 단계
      ↓
④ 오답 원인 태그 선택 (몰라서/실수/시간부족/함정)
      ↓
⑤ (영어 과목) 하위 카테고리 선택
      ↓
⑥ 저장 → box 0, 다음 날부터 복습 대상
```

**규칙**

- OCR 결과를 **확인 없이 바로 저장하지 않는다.** ③은 건너뛸 수 없다. OCR은 틀린다.
- `ocrRawText`(원본)와 `userEditedText`(수정본)를 **둘 다 보존**한다. 표시에는 수정본을 쓴다.
- OCR 실패 시 얼럿 대신 **빈 텍스트 필드 + 직접 입력 안내**로 넘어간다. 실패가 막다른 길이 되지 않게 한다.
- 인식 언어: 한국어 + 영어. 수학 기호/LaTeX는 1차 범위 밖 (텍스트 위주 문제 대상).

### 복습 플래시카드 UI

- 오늘 due인 카드를 넘기며 복습한다.
- 카드마다 **"맞음 / 틀림"** 두 개 동작만. 난이도 5단계 같은 걸 두지 않는다.
- 결과에 따라 Leitner box 갱신 (→ [03](03-domain-logic.md#3-스페이스드-리피티션)).
- 밀린 카드도 계속 due로 남는다. "밀렸습니다" 같은 압박 문구를 쓰지 않는다.

## 6. 온보딩 (9단계)

최초 실행 시 3~4단계 마법사. **건너뛰어도 앱이 정상 동작해야 한다.**

```
① 학년 / 입학연도 입력 → 등급제 자동 제안 (수동 변경 가능)
② 이수 과목 등록            [건너뛰기]
③ 학교/학원 시간표 최초 등록 [건너뛰기]
④ 완료
```

- **로그인 단계를 포함하지 않는다.**
- 모든 값은 나중에 설정에서 채울 수 있다. 필수 입력으로 막지 않는다.
- 완료 여부는 `@AppStorage` 플래그로 관리한다.

---

## 7. 화면 전환·애니메이션

- 시스템 기본 전환만 사용한다. 커스텀 트랜지션을 만들지 않는다.
- 리스트 추가/삭제는 SwiftData 변경에 따른 기본 애니메이션에 맡긴다.
- 로딩이 필요한 곳은 OCR **한 곳뿐**이다. 다른 곳에 스피너를 두지 않는다 (로컬 DB는 즉시 응답).

## 8. 입력 검증 정책

| 대상 | 규칙 | 실패 시 |
|---|---|---|
| 과목명 · 회차명 | 공백만 입력 불가 | 저장 버튼 비활성화 |
| 이수단위 | `> 0` | 저장 버튼 비활성화 |
| 원점수 · 평균 | `0...100` 권장이나 강제하지 않음 | 경고 없이 저장 (학교마다 만점이 다름) |
| 표준편차 | `> 0` 이어야 추정 가능 | 추정 등급만 숨김. 저장은 허용 |
| 석차등급 | `1...tierCount` | 범위 밖 입력 불가 (Stepper/Picker 사용) |
| 시간표 | `startTime < endTime` | 인라인 안내 문구 |

**저장 버튼 비활성화를 기본 수단으로 쓰고, 얼럿을 남발하지 않는다.**
